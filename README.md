# Dynamic Weather Scapes

Update the Weather Watch app so the background changes automatically according to the viewer's local time when they open the website.



Automatic Background



- 🌅 Morning: Show a bright sunrise/morning background with soft daylight.

- ☀️ Afternoon: Show a bright daytime background with the sun and blue sky.

- 🌇 Evening: Show a sunset background with warm evening colors.

- 🌙 Night: Show a dark nighttime background with stars or a moon.



The app should detect the viewer's local time automatically and switch the background without the viewer needing to change anything.



The background should also update automatically if the viewer keeps the website open while the time changes from morning → afternoon → evening → night.



Keep the existing features:



- Time-based greetings

- Polokwane, Braamfontein, Pretoria, and Cape Town

- Pictures for each location

- Current weather and 7-day forecast

- Dark Mode / Light Mode

- Search bar

- Temperature in °C



Make the background transition smooth and visually appealing, while keeping all weather information easy to read.
